# Orion project brief

Project Orion is a fictional research workspace release scheduled for 14 May. Maya Patel is the release owner and the main point of contact for the launch decision.

## Launch checklist

Before launch, the team must complete a security review, validate that document citations point to the correct page, and test the upload recovery flow. The support team will prepare a short onboarding guide.

## Open risks

The local AI model can be slow on memory-constrained laptops. The team should measure response time separately from normal API traffic. Any answer without adequate source evidence should state that the document does not contain enough information.

## Next meeting

The launch team meets every Tuesday at 10:00 to review progress and blockers. Maya maintains the list of decisions and follows up on open security issues.
